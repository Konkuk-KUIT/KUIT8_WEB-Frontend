# KUIT 8기 Web 3주차 Mission

이번 미션에서는 여러 화면에서 반복되는 UI를 공통 컴포넌트로 분리하고, 필요한 데이터를 Props로 전달하여 화면을 구성합니다.

`Stores` 화면과 일부 공통 컴포넌트가 미리 제공됩니다. 제공된 코드를 참고하여 `Store`와 `Cart` 화면을 구현해 주세요.

## 시작하기

현재 폴더에서 다음 명령어를 실행합니다.

```bash
npm install
npm run dev
```

## 제공되는 설정

- Vite 기반 React 프로젝트
- React Router와 페이지 경로
- Tailwind CSS
- Pretendard 폰트
- 화면 구현에 사용할 더미 데이터

## 제공되는 코드

- Tailwind CSS로 구현된 `Stores` 화면
- `BackBar`, `Button`, `StoreItem`, `MenuItem`, `OrderBar` 컴포넌트
- `stores.js` 더미 데이터

Routing 코드는 미리 제공되므로 직접 구현하지 않아도 됩니다. 이번 미션에서는 `Store`와 `Cart` 화면의 컴포넌트 설계와 스타일링에 집중합니다.
다만 필요에 따라 제공된 코드를 수정해도 괜찮습니다.

## 더미 데이터

가게와 메뉴 정보는 다음 파일에서 확인할 수 있습니다.

```text
src/models/stores.js
```

화면에 필요한 텍스트와 가격은 가능한 한 이 데이터를 Props로 전달하여 사용해 주세요.

## 직접 구현할 화면

- `src/pages/Store/Store.jsx`
- `src/pages/Cart/Cart.jsx`

피그마를 참고하여 두 화면을 구현하고, 반복되거나 역할이 분명한 UI는 컴포넌트로 분리합니다. 제공된 컴포넌트는 그대로 사용하거나 필요한 형태에 맞게 수정해도 됩니다.

이번 주차에서는 버튼 동작이나 장바구니 상태 변경을 완성하지 않아도 괜찮습니다. 정적인 화면을 구현하면서 컴포넌트의 책임과 Props 구조를 고민하는 데 집중해 주세요.

## 스타일링 방식

제공된 `Stores` 화면은 Tailwind CSS로 작성되어 있습니다. 미션에서는 아래 방식 중 원하는 것을 선택할 수 있습니다.

- CSS Module
- styled-components와 같은 CSS-in-JS
- Tailwind CSS

한 프로젝트 안에서 여러 방식을 불필요하게 섞기보다는, 자신이 선택한 방식으로 일관성 있게 작성하는 것을 권장합니다.

## 참고 사항

- 피그마와 최대한 유사하게 구현하되 완전히 동일할 필요는 없습니다.
- 화면에 제시된 주요 컴포넌트는 모두 표시되어야 합니다.
- 반응형 구현은 필수가 아니며 `390px` 너비의 고정형 화면으로 구현해도 됩니다.
- SVG 이미지는 `public` 폴더의 개별 파일을 사용합니다.
- 상태 관리와 실제 주문 기능은 이후 주차에서 구현합니다.
